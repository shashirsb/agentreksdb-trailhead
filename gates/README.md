# Trailhead gates for AgentreksDB

These files turn the `shashirsb/agentreksdb` repo into one where code reaches `main` only through the
Trailhead pipeline: generated by the pinned model, signed by the pipeline, proven by tests and policy,
and merged in the weekly train after a governor decision.

| File | Gate | Blocks merge? |
| --- | --- | --- |
| `.github/workflows/gate-tests.yml` | fmt, clippy `-D warnings`, nextest (unit + property), doc tests, coverage ratchet, cargo-mutants on changed code (≥ 80% caught) | yes |
| `.github/workflows/gate-perf.yml` | instruction counts on every PR (> +2% fails); wall-time macro suite on a bare-metal runner behind `perf:macro` and nightly | instructions: yes · macro: when labelled |
| `.github/workflows/gate-diff-policy.yml` | diff manifest → `trailhead policy check`, semgrep, cargo-deny, cargo-audit, gitleaks; SARIF upload; signed-ready `gate-verdict.json` artifact | yes |
| `.github/workflows/gate-attestation.yml` | every commit gitsign-signed by the Trailhead workflow identity, with `Generated-By`, `Spec-Hash`, `Trailhead-Intent` trailers | yes |
| `.github/workflows/gate-ai-review.yml` | PR-Agent review by a non-Claude model, reading the spec and prompt log | no — advice for the governor |
| `.github/workflows/train-gate.yml` | merge only with `train/<current>` + `decision:merge`; Sunday/Friday 00:00 PT tick to the Trailhead API | yes |
| `.github/workflows/close-human-prs.yml` | closes PRs not opened by the Trailhead App, pointing to Trailhead | — |
| `diff-policy.toml` | BLOCK/WARN rules read by `trailhead policy check` | — |
| `semgrep/rust-trailhead.yml` | semantic Rust rules (egress, processes, secret env, embedded files, Trojan Source, hostname gates) | — |
| `CODEOWNERS` | human-only paths: tests, CI, gates, build scripts, lockfile, crypto/auth/net, governance | — |
| `rulesets/main.json` | the `main` branch ruleset | — |
| `coverage-floor.txt` | coverage ratchet floor; it may rise, never fall | — |

## Install

From a checkout of `agentreksdb` (paths assume the Rust workspace lives in `agentreksdb/`; set the
repository variable `WORKSPACE_DIR` if it moves):

```bash
TH=../agentreksdb-trailhead/gates
mkdir -p .github/workflows gates/semgrep
cp $TH/.github/workflows/*.yml .github/workflows/
cp $TH/CODEOWNERS .github/CODEOWNERS
cp $TH/diff-policy.toml $TH/coverage-floor.txt gates/
cp $TH/semgrep/rust-trailhead.yml gates/semgrep/
# This install commit is human-authored, so it is the one commit that goes in before the ruleset:
git add .github gates && git commit -s -m "Install Trailhead gates" && git push
gh api -X POST repos/shashirsb/agentreksdb/rulesets --input $TH/rulesets/main.json
```

## Repository settings

Variables: `WORKSPACE_DIR` (default `agentreksdb`), `TRAILHEAD_URL`, `TRAILHEAD_BOT_LOGIN` (the App's bot
login, e.g. `agentreks-trailhead[bot]`), `TRAILHEAD_IDENTITY_REGEXP` (only if the signing workflow path
changes), `REVIEW_MODEL`, `BENCHER_PROJECT`.

Secrets: `TRAILHEAD_TICK_TOKEN` (bearer token the API accepts on `/api/train/tick`), `OPENAI_KEY` (the
reviewer model — a different family from the generator), `BENCHER_API_TOKEN`.

Runner: register one self-hosted runner labelled `perf-bare-metal` on a dedicated machine (fixed CPU
governor, SMT off, `isolcpus`, ASLR off) for the macro benchmarks.

## Required checks

Mark these as required (the ruleset already lists them): `gate-tests / static`, `gate-tests / nextest`,
`gate-tests / coverage`, `gate-tests / mutants`, `gate-perf / instructions`, `gate-diff-policy / policy`,
`gate-attestation / verify`, `train-gate`.

Not required: `gate-ai-review / pr-agent` (advisory), `gate-perf / macro` (runs only when labelled).

## Notes before turning enforcement on

- Pin every action to a full commit SHA (lines marked `TODO(pin)`).
- The ruleset does NOT use GitHub's `required_signatures`: GitHub does not recognise Sigstore (gitsign)
  signatures, so it would refuse every Trailhead commit. `gate-attestation` (a required check, pinned to
  GitHub Actions via `integration_id`) verifies them instead, and the merge queue uses MERGE (not squash or
  rebase) so the signed commits land on `main` unchanged. The only merge commits allowed are GitHub's own.
- `required_approving_review_count` is 0: the governor's decision is enforced by `train-gate`
  (`decision:merge` label, set only by the Trailhead App). Code-owner review is still required for
  sensitive paths (tests, CI, gates, crypto/auth/net), which diff-policy also blocks.
- Merge queues exist only for organization-owned repos. On a personal account, drop the `merge_queue`
  rule (`deploy/gcp/setup.sh` does this automatically); Trailhead then merges directly, and all required
  checks still apply. Move the repos to a GitHub organization to get batched merges.
- `bypass_actors` is empty on purpose, including for org admins. Changing it is a governance decision and
  shows in the ruleset history.
- Add `benches/iai.rs` (iai-callgrind) to the workspace so the instruction-count gate measures something;
  until then it warns and passes.
