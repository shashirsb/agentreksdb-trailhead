The weekly train

Cutoff Sunday, decision Friday.

Every new merge request joins the next train. At Sunday 00:00 Pacific the train closes; the governing body then has until Friday 00:00 Pacific to check, review, and merge each branch or put it on hold. Silence is a hold, never a merge.

Releases

What each train delivered.

Every Friday the governing body closes a train. Each release lists the changes it merged, who asked for them, why the governor approved them, and links to the signed commit and pull request. Held and declined branches are counted too.

The governor queue

What's waiting at the summit.

Branches with every gate green, plus anything a gate flagged. Humans decide; they never write code. Every decision needs a reason and is written to the public ledger.

Public ledger

Everything, in order, forever.

Every prompt, model response, gate verdict, governor decision and credit movement is an event. Each event's hash covers the one before it, so changing or deleting history breaks the chain for everyone to see.

02

Every line comes from the model we chose, on our keys. Rotation is a public decision.

04

100% public

Every prompt, verdict, decision and credit is in the hash-chained ledger.

Defense in depth

Four gates, four different jobs.

Prompt guardrails

Advisory

Inspect the request and route it. Probabilistic, so never the wall.

Tests · perf · QA

Blocking

Catch the mistakes AI makes. Test files are human-owned so the model can't weaken them.

Diff-policy gates

Blocking

The only layer aimed at malice. Reads every byte of the diff and hard-stops to a human.

Human + AI governor

Final

A reviewer from a different model family advises; humans decide what merges.

Open source forever

The charter, in plain words.

These commitments are written so they can only ever be made stronger.

LICENSE

Apache-2.0, always

OSI-approved licenses only. AI-generated files are also dedicated to the public domain where copyright doesn't apply.

NO ENTERPRISE EDITION

One edition, for everyone

No proprietary tier, ever. Deploy kits for your own cloud ship in the open repo.

NO CLA

Nobody can relicense it

Contributions use a DCO sign-off. No contributor license agreement that would allow a future relicense.

AI-ONLY CODE

Intent in, code out

Code reaches main only as a backend-signed commit from the pinned model. Human-written code PRs are closed automatically.

TRANSPARENCY

Everything public

Prompts, decisions and spend are in the hash-chained ledger, which the database itself refuses to edit. Anyone can verify it against the signed checkpoint.

GOVERNANCE

Five elected governors

Staggered one-year terms, at most two per employer, recusal on conflicts, and an independent appeal board.
